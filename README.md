# 도로안심 GPS v0.3 — 지도 / GPS / 백그라운드 경고

## 구현
- OpenStreetMap/Leaflet 지도 (인터넷 필요), 현재 위치와 정확도 원
- Android GPS 및 네트워크 위치 수신, 주행속도 표시
- 포그라운드 서비스에서 위치 추적과 **사용자 지정 속도 기준 초과 경고** 처리: 앱 화면이 보이지 않아도 서비스가 살아 있는 동안 경고 가능
- 설정 속도 30~150km/h, 진동/한국어 음성 개별 선택, 설정값 저장
- 30초 경고 간격, 부정확한 위치·비정상 속도 필터링
- GPS 시작/중지, 내 위치로 지도 이동, 상태 알림

## 중요한 한계
- **법정 제한속도/단속카메라/실시간 사고/공사 데이터는 연동하지 않았습니다.** 앱이 보여 주는 속도 기준은 사용자가 임의로 정한 값이며 실제 도로의 제한속도가 아닙니다.
- 외부 OSM 타일 및 Leaflet CDN에 인터넷 연결 필요, 오프라인 지도 미지원.
- 백그라운드 위치 추적은 Android의 위치 권한·배터리 정책·기기 상태에 따라 중단될 수 있음. 삼성 갤럭시 실기기 검증 필요.
- 음성 안내와 음악 동시 재생, 운전 중 정확도는 실기기 테스트 필요.
- 본 앱은 개발용 시험판이며 운전 중 조작하거나 안전 판단에 의존하지 마세요.

## 빌드
GitHub 저장소 루트에 압축 해제된 파일/폴더를 업로드 후 Commit changes. Actions의 Build Android APK 성공 실행에서 Artifacts의 RoadSafetyGPS-APK 다운로드. APK를 설치해 테스트.

## v0.4 J 아이콘 변경
- 안드로이드 기본 아이콘 대신 금색 테두리·네온 블루의 J 로고 아이콘을 모든 화면 밀도용 리소스로 추가했습니다.
- AndroidManifest.xml에 앱 아이콘 및 원형 아이콘을 지정했습니다.
- versionCode를 4로 올렸습니다. APK는 GitHub Actions에서 새로 빌드해야 합니다.

## v0.5 전자계기판
- 상단 지도와 하단 디지털 계기판을 가용 화면 높이 기준 정확히 1:1로 배치했습니다.
- 속도 숫자(km/h), 0~180km/h 반원형 게이지, 설정 경고 속도 초과 시 주황색 게이지 표시.
- 지도 아래 계기판과 별도로 GPS 조작/설정 버튼은 화면 하단에 유지합니다.
- GPS 속도 값이 없을 때는 -- 로 표시합니다.
